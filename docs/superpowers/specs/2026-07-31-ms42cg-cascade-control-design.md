# MS42CG级联滚球控制设计

## 目标

在现有K230视觉、LCD、RTSP和D36A步进驱动工程中接入MS42CG编码器，形成：

1. 视觉钢球位置外环；
2. 摆杆真实角度内环；
3. PWM绝对角度上电恢复；
4. AB相高速增量反馈；
5. Z相零位复核；
6. 零位校准持久化到SD卡。

现有通过累计STEP脉冲估算摆杆角度的方式将被真实编码器角度取代。

## 硬件连接

编码器为3.3V单端输出，与K230 GPIO直接连接：

| MS42CG | K230物理针脚 | GPIO | 用途 |
|---|---:|---:|---|
| A | 27 | IO19 | AB正交A相 |
| B | 29 | IO20 | AB正交B相 |
| Z | 31 | IO32 | 每圈索引脉冲 |
| PWM | 33 | IO33 | 12位绝对角度占空比 |
| GND | 30或34 | GND | 编码器与K230共地 |
| 3.3V | 17 | 3.3V | 编码器逻辑供电 |

D36A保持现有连接：STEP=IO42/PWM0、DIR=IO5、EN=IO6。

## 控制结构

### 视觉外环

运行频率随摄像头/KPU帧率，目标约28Hz。输入为钢球相对于触摸目标T的厘米误差和速度，输出为`target_rod_angle_deg`，范围限制为±16°。保留当前线性位置项、速度阻尼项和非线性边缘增强项。

### 编码器角度内环

使用`Timer(-1)`以5ms周期运行，目标200Hz。官方文档说明Timer(-1)是唯一软件定时器，因此现有一次性视觉看门狗必须合并到该周期控制器中，不能创建第二个Timer(-1)。

内环输入：

- 外环目标摆杆角；
- AB累计得到的真实摆杆角；
- AB差分得到的摆杆角速度；
- 视觉数据时间戳；
- 编码器最后变化时间戳。

内环采用带抗饱和的PID，输出有符号STEP频率。频率绝对值映射至D36A PWM，符号映射至DIR。死区应不小于一个编码器计数，即0.087890625°。最大频率维持800Hz，频率斜坡维持24000Hz/s，避免突然反向丢步。

由于CanMV软件定时器`hard=False`会受解释器负载影响，程序必须统计实际内环频率；低于80Hz持续200ms时停止STEP并显示`CTRL SLOW`，不能悄悄降级为开环。

## ABZ解码

MS42CG为1024线编码器。A/B双边沿四倍频后：

```text
4096 count/rev
360 / 4096 = 0.087890625 degree/count
```

A、B均配置双边沿IRQ，使用16项Gray状态转移表更新预分配整数计数器。IRQ中只读取A/B电平、更新整数和时间戳，不打印、不写文件、不调用PWM，避免阻塞和内存分配。

非法Gray跳变累计为错误计数。连续错误超限时停止电机并显示`AB FAULT`。

Z相只记录索引位置及一致性，不在运行中突然清零。如果Z相位置相对已保存索引漂移超过2°，停止STEP并显示`Z MISMATCH`。

## PWM绝对角度

PWM仅在以下阶段启用双边沿采集：

1. 上电初始化；
2. 用户点击水平零位；
3. 用户主动重新校准。

获得连续有效周期后立即关闭PWM IRQ，避免约2k次/秒的PWM边沿回调与AI、AB解码争抢解释器。

默认协议按4096级单圈占空比解释：

```text
absolute_count = round(high_us / period_us * 4096) mod 4096
```

实现必须提供`PWM_DUTY_MIN`、`PWM_DUTY_MAX`和`PWM_INVERT`配置，以适配MS42CG批次差异。周期越界、占空比越界或抖动超限时判定PWM无效。

## 零位校准与持久化

用户把摆杆置于机械水平后点击现有`ZERO`区域：

1. 停止STEP；
2. 采集多帧PWM绝对角度并取中位数；
3. 将该绝对计数记为`zero_abs_count`；
4. 将当前AB累计计数映射为0°；
5. 原子保存校准文件。

文件路径：`/sdcard/ms42cg_encoder_calibration.json`。使用临时文件写入、关闭后再替换正式文件。格式：

```json
{
  "version": 1,
  "encoder_model": "MS42CG",
  "counts_per_rev": 4096,
  "zero_abs_count": 2874,
  "direction_invert": false,
  "z_index_count": 0
}
```

启动时读取文件与当前PWM绝对计数，使用环形差值恢复摆杆角：

```text
delta = current_abs - zero_abs
delta > 2048  => delta -= 4096
delta < -2048 => delta += 4096
angle_deg = delta * 360 / 4096
```

校准缺失或PWM无效时保持D36A禁用，并显示`ENC ZERO REQUIRED`。不得退回累计STEP估算角度。

## AB与PWM融合

上电时由PWM给AB计数器赋初始绝对位置。运行期间以AB为唯一高速控制反馈。PWM不持续采集；在停机或重新校准阶段复核AB累计值。

AB与PWM差值：

- ≤0.5°：允许平滑修正；
- 0.5°到2°：记录`ENC DRIFT`，保持电机停止后校正；
- >2°：停止STEP并显示`ENC MISMATCH`。

## 故障安全

- 视觉超时150ms：停止STEP，D36A保持使能以保持真实当前角度；
- 编码器在命令运动期间80ms无计数变化：停止并显示`ENC STALL`；
- 角度超出±16°：只允许向安全方向运动；
- 控制定时器过慢：停止并显示`CTRL SLOW`；
- AB非法跳变超限：停止并显示`AB FAULT`；
- PWM启动校验失败：禁止启动并显示`PWM INVALID`；
- 所有故障通过LCD和UART输出，但故障处理不得依赖网络或RTSP。

## 显示与遥测

LCD持续显示：

- `A:`真实摆杆角；
- `T:`外环目标角；
- `V:`摆杆角速度；
- `E:`角度内环误差；
- `F:`STEP频率；
- `ENC:`AB/PWM/Z/故障状态；
- 实际内环Hz。

UART保留现有球位置数据，并追加编码器状态字段。不得降低每帧视觉控制数据发送频率。

## 测试要求

纯函数测试覆盖：

- 16状态正交解码、正反转和非法跳变；
- 0/4095跨界绝对角计算；
- PWM占空比到12位计数转换；
- 零位文件校验与损坏回退；
- 角度PID、积分抗饱和、反向减速；
- ±16°安全限位；
- 视觉超时、编码器堵转、AB/PWM不一致；
- 原有视觉、绿色水管、RTSP和步进测试全部继续通过。

上板验收顺序：PWM静态角度、AB手转计数、Z脉冲、水平零位保存、断电恢复、低速闭环、边缘回收、车辆静态扰动、车辆循迹动态测试。

## 依据与限制

- CanMV官方Pin API支持GPIO双边沿IRQ，但`hard`参数不受支持；IRQ代码必须极短。
- CanMV官方Timer API规定Timer(-1)为唯一软件定时器，最小周期5ms；`hard=False`回调可能合并或丢弃。
- CanMV官方PWM API说明PWM0可映射IO42，保留现有D36A STEP输出。
- 当前固件为CanMV v1.8 Hiwonder K230；实现不得假设最新开发分支独有API。
- 方案3受MicroPython实时性限制，必须用实际内环频率和故障停机暴露性能不足，不能伪装成硬实时闭环。
